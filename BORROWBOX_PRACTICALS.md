# BorrowBox – practicals implemented

The current build integrates these Mobile Application Development practical concepts:

3. LinearLayout UI and screen design (plus layout demonstration)
4. FrameLayout, RelativeLayout and TableLayout demo
5. TextView, EditText and AutoCompleteTextView
6. Button, ImageButton and ToggleButton
7. CheckBox
8. RadioButton / RadioGroup
9. ProgressBar
10. ListView and GridView
11. ImageView and ScrollView
12. Custom Toast + DatePicker + TimePicker
13. Activity lifecycle demo
14. Explicit intents
15. Implicit intents (web, email, share)
16. Intent filter for receiving shared text
17. Camera capture with runtime permission
18. Horizontal/vertical fragment demonstration
19. BroadcastReceiver for connectivity status
20. SQLite insert, update, delete and search
21. SMS with runtime SEND_SMS permission and safe fallback to the SMS composer
22. Bluetooth enable, discoverability, paired-device/discovery list and Bluetooth sharing
23. Text-to-speech and speech-to-text
24. GPS/location with runtime permissions and Maps intent

Core BorrowBox application features:
- Firebase Email/Password authentication
- Firebase Realtime Database support for Users, Books and Requests
- Local fallback for added books so the demo remains usable when Firebase write access is unavailable
- Modern lavender / baby-blue / baby-pink visual theme
- Book details, borrow request, search, notifications and profile
