# 📚 BorrowBox — Borrow, Don't Buy

BorrowBox is an Android application designed to make book sharing simple and convenient for students.

The application allows students to list books they are willing to lend, search for available books, view book details, and send borrowing requests to the respective owners.

## 📱 Features

- 🔐 User Registration and Login
- 📚 Add and list books
- 🔎 Search books by title, author and category
- 🏷️ Book categories
- 👤 User profile
- 📖 Book details
- 📩 Borrow request system
- 🔔 Notifications
- 📍 Location/GPS practical
- 📱 SMS sharing
- 🔊 Text-to-Speech
- 📡 Bluetooth sharing
- 📤 Share text using Android Intent
- 💾 Local SQLite database practical
- ☁️ Firebase integration

## 🛠️ Technologies Used

- **Java**
- **XML**
- **Android Studio**
- **Firebase Authentication**
- **Firebase Realtime Database**
- **SQLite**
- **Android SDK**
